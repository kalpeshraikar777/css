# CSS Selectors Task

A small practice page that shows different ways of selecting elements in CSS -
tag selectors, class selectors, id selectors, and structural selectors like
nth-child (used for the parts where id/class weren't allowed).

## Files
- index.html - the markup
- style.css - all the styling
- Readme_css_task.md - this file

## What's covered
- Body background color
- 3 heading tags (h1, h2, h3) sharing a class, styled together
- One heading also has its own id for a background color
- Specific words inside a heading colored individually with spans
- 3 paragraphs styled purely through the p tag (no id/class)
- One paragraph singled out with an id for its own color
- A word inside a paragraph highlighted using a nested tag selector (p b)
- Two lists where links and list items are styled using nth-child instead
  of adding classes or ids

## How to run
Open index.html in a browser - style.css is linked and loads automatically.
